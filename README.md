A scroll-driven, cinematic portfolio built with **Next.js 16**, **React**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, **GSAP**, and **Lenis**.

---

## Features

- **Scroll-driven animations** — Every section responds to scroll position
- **Fluid cursor effect** — Interactive WebGL splash cursor on desktop
- **3D scroll-stack projects** — Cards stack and scale as you scroll
- **Animated navigation** — Full-screen overlay with clip-path transitions
- **Parallax footer reveal** — Footer scales into view on scroll
- **Simple CMS Dashboard** — Edit all portfolio data via `/dashboard`

---

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion, GSAP, Lenis
- **CMS:** JSON-based API (simple CRUD)

---

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

---

## Dashboard

Visit `/dashboard` to edit all portfolio content — projects, skills, about info, social links, etc.
